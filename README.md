# PesaShield

PesaShield is a machine-learning project for detecting SMS spam and financial scams.

The project starts with scam patterns common in Kenya, such as fake M-Pesa messages, loan scams, phishing links, and impersonation attempts. It is designed to grow into a global SMS scam-detection system.

## Project Goals

- Detect normal SMS messages, spam, and financial scams
- Identify scams such as fake payment alerts, loan offers, phishing links, and impersonation
- Build a beginner-friendly machine-learning model using Python
- Improve the system later with Kenya-specific and global scam examples

## Dataset

This project begins with the UCI SMS Spam Collection dataset.

- Total messages: 5,574
- Ham (normal messages): 4,827
- Spam messages: 747

Source: [UCI SMS Spam Collection](https://archive.ics.uci.edu/dataset/228/sms%2Bspam%2Bcollection)

The dataset is licensed under CC BY 4.0.

## Planned Labels

| Label | Meaning |
|---|---|
| `safe` | A normal, legitimate SMS |
| `general_spam` | Generic unwanted or promotional SMS |
| `financial_scam` | Fake payment alerts, phishing, loan scams, or impersonation |

## Technologies
